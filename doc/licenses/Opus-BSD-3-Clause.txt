Opus-derived code in DREAM

src/sourcedecoders/concealment.cpp is a C++ port of the float CELT packet loss
concealment of Opus 1.6.1 (celt/pitch.c, celt/celt_lpc.c, celt/celt_decoder.c);
src/sourcedecoders/opus_dll.h reproduces declarations from the Opus headers.
